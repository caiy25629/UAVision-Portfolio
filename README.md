# UAVision－無人機海岸垃圾監測系統

## 專案簡介

本專題結合無人機影像、深度學習與地理資訊技術，
建立海岸垃圾智慧辨識系統。

透過無人機拍攝海岸影像，
利用 YOLOv8 模型進行垃圾辨識，
並結合 GPS 座標資訊標示垃圾位置，
協助管理人員提升巡查效率。

---

## 個人負責工作

- 海岸垃圾影像資料蒐集
- 無人機飛行與空拍影像拍攝
- Roboflow 標註與資料前處理
- YOLOv8 模型訓練
- 訓練參數調整與效能分析
- Kaggle GPU 雲端訓練環境建置與操作
- 專題報告與簡報製作

---

## 使用技術

- Python
- YOLOv8
- OpenCV
- Roboflow
- Kaggle GPU

---

## 專題成果

- 完成海岸垃圾智慧辨識系統建置
- 建立無人機影像垃圾辨識流程
- 模型 mAP50 最高達 0.908
